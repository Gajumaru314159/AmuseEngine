詳解

XMLの要素を表現するクラス

属性、子ノード、テキストコンテンツを保持します。

特殊ノード
  • #comment - XMLコメント（属性"content"にコメント内容を保持）
  • #text - テキストノード（属性"content"にテキスト内容を保持）
