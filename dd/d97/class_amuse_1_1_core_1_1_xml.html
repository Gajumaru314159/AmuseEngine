詳解

XMLドキュメント全体を表現するクラス

XmlNodeを継承し、ファイルI/OとXPathサブセット検索機能を追加します。 parse()でXMLを読み込むと、ルート要素がXml自体に展開されます。

使用例
Xml xml;
xml.parse("<html><body><div/></body></html>");
// xml.name == "html"
// xml.at("body").at("div") でアクセス
// xml.find("/html/body/div") でも検索可能

XPathサブセット (find/exists)
サポートする構文:
  • / で階層を区切る（絶対パス）
  • [n] で n 番目の同名要素を指定（1始まり）
  • #comment でコメントノードを指定
  • #text でテキストノードを指定
  • 名前空間プレフィックス（例: svg:rect, xlink:href）

サポートしない構文:

  • 軸指定（parent::, ancestor:: など）
  • 述語内の条件式（‘[@attr='value’]など）
  • 関数（text(),contains()など） -//による子孫検索
  • ワイルドカード（*`）
