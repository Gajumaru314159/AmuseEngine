Locale クラス
Core

説明

ロケール

IETF言語タグを表すクラス

  • language (言語)
  • script (スクリプト)
  • region (地域)
  • variant (バリアント)
  • extension (拡張)
  • privateuse (プライベート使用) で構成され、それぞれの要素はハイフンで区切られる。 例: ja-JP-u-ca-japanese
    参照
    https://en.wikipedia.org/wiki/IETF_language_tag
