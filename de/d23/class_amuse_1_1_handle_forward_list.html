template<typename T>
class Amuse::HandleForwardList< T >

ハンドル管理式単方向連結リスト

このコンテナは要素をコンテナ内部で管理せずハンドル内で管理する。
よって、ハンドルのデストラクタが呼ばれるとリストの管理から外される。
要素のデストラクタが呼ばれるタイミングはハンドルが破棄されるタイミングである。
通常のリストと比べ排他的制御が入るため速度は遅いが、delegateなどのインスタンスの寿命と合わせる必要がある場合に使用する。

使用方法：

Amuse::HandleForwardList<Amuse::s32> ls;
using Handle = Amuse::HandleForwardList<Amuse::s32>::Handle;
{
Handle Handle;
ls.emplace_front(Handle,123);
std::cout<<ls.size()<<std::endl; // 1
}
std::cout<<ls.size()<<std::endl; // 0
